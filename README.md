# ModelagemDeSistemas

<ul>Regras de negócios (RN):
<li>RN01 - Um produto deve possuir matéria-prima vinculada</li>
<li>RN02 - O estoque não pode ser negativo</li>
<li>RN03 - Um pedido só pode ser aprovado se tiver estoque</li>
<li>RN04 - Cada lote ter ratreabilidade</li>
<li>RN05 - Um cliente deve estar cadastrado para realizar pedidos</li>
<li>RN06 - A produção deve registrar perdas e rendimento </li>
<li>RN07 - Transporte deve estar vinculado a um pedido</li>
</ul>

<ul>
Requisitos funcionais (RF):
<li>RF01 - Cadastrar matéria-prima</li>
<li>RF02 - Registrar produção</li>
<li>RF03 - Controlar estoque</li>
<li>RF04 - Cadastrar cliente</li>
<li>RF05 - Registrar pedido</li>
<li>RF06 - Controlar transporte</li>
<li>RF07 - Gerar relátorio de produção</li>
</ul>

<ul>
Requisitos Não Funcionais (RNF):
<li>RNF01 - Sistema Web</li>
<li>RNF02 - Interface simples</li>
<li>RNF03 - Tempo de resposta rápida</li>
<li>RNF04 - Segurança de dados</li>
<li>RNF05 - Disponibilidade 24h</li>
</ul>
