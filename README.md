# ModelagemDeSistemas

Regras de negócios (RN):
RN01 - Um produto deve possuir matéria-prima vinculada
RN02 - O estoque não pode ser negativo
RN03 - Um pedido só pode ser aprovado se tiver estoque
RN04 - Cada lote ter ratreabilidade
RN05 - Um cliente deve estar cadastrado para realizar pedidos
RN06 - A produção deve registrar perdas e rendimento 
RN07 - Transporte deve estar vinculado a um pedido


Requisitos funcionais (RF):
RF01 - Cadastrar matéria-prima
RF02 - Registrar produção
RF03 - Controlar estoque
RF04 - Cadastrar cliente
RF05 - Registrar pedido
RF06 - Controlar transporte
RF07 - Gerar relátorio de produção

Requisitos Não Funcionais (RNF):
RNF01 - Sistema Web
RNF02 - Interface simples
RNF03 - Tempo de resposta rápida
RNF04 - Segurança de dados
RNF05 - Disponibilidade 24h
